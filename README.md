# MiniMax H3 FL2VA 八卡适配

队伍从容应对，队长徐晨宇。基于 InfiniLM、InfiniCore 和 NineToothed，在海光 gfx936 整机八卡上完成首帧与文本条件视频推理。本目录是 R2 实测版本的本地审阅副本，尚未公开发布或最终提交。

2026 年 11 月 9 日，八卡作业 `9735e4fd51c3` 正常退出并释放资源。统一小狗图片、提示词 `A dog falls asleep`、seed 42、请求 50 步、124 帧完整运行。输出 768×928、24 fps、H.264，含 AAC 32 kHz 双声道音频；全部视频帧和音频可解码。视频约 5.1667 秒。

以独立原版参考作业 `c37023974619` 的同配置视频为对照，未修改的 `InfiniLM/examples/minimax_h3_compare.py` 返回 Size PASS、Length PASS、平均 SSIM 97.394%。这属于本地原版参考自测，官方相似度验收仍待评测，不能据此保证正式通过或获奖。

本次原生入口端到端 874.538 秒，原版参考 600.491 秒，当前尚无相对原版的端到端加速。计时口径与各阶段耗时见 `evidence/r2-public-result-summary.json`；读取现有视频的比较脚本计时不能作为生成耗时。

## 实现和使用

- 入口：`run_eightcard.py fl2va`；完整操作见 `RUN-EIGHT-CARD.md`。
- 单进程管理八个原生 TP 工作线程，保留指定权重、条件处理、生成步数和媒体规格。不要使用 torchrun 启动八份完整模型。
- 新增或重写的设备计算使用 NineToothed 编译链；编译器宿主适配见 `platform/COMPILER_REPRODUCTION.md`。
- R2 增加 Torch 生产流完成后再交接原生指针的宿主同步，并调整 Nine AdaLN 的 BF16 舍入顺序以对应原版计算。
- 八卡通信、逐卡算子、H3 TP1/TP8、Qwen TP1/TP8 及补充交接和原生分派测试已通过，资格报告对应作业 `689bd8fcf1cc`。

## 完整视频优化实验

R3 将长序列 Q/K 矩阵乘路径改为 BF16 输入，并经 NineToothed 编译链执行。
两次八卡完整运行均通过组件、规格及124帧完整解码检查。
端到端分别740.365和733.288秒，相对R2缩短15.34%和16.15%；
独立原版参考SSIM分别95.816%和94.628%，低于R2的97.394%。
最终推理路径保留R2；R3三份实验源码只位于tests/experiments/r3-runtime，未作为默认后端。
可核对evidence/r3-full-video-experiment-summary.json及两份原版比较结果。
这是单个公开样例的两次实验，尚不能证明隐藏用例效果或官方验收。
